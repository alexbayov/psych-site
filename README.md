# Сайт Александра Баёва

Статический сайт клинического психолога и КПТ-специалиста Александра Баёва.

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

После запуска сайт доступен по адресу `http://127.0.0.1:4173`.

Перед публичным запуском нужно подтвердить тексты, цену и формат работы,
контакт для записи, юридический статус и домен.
